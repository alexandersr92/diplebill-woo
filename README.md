# DipleBill WooCommerce Connector

Este plugin conecta la tienda WooCommerce con el sistema de facturación y POS **DipleBill**, sincronizando productos, inventarios y ventas en tiempo real.

## Instalación
1. Descarga el repositorio como ZIP o clónalo dentro de la carpeta `wp-content/plugins/diplebill-woo`.
2. Activa el plugin desde el panel de administración de WordPress.
3. Ve a **WooCommerce > DipleBill Conector** para realizar la configuración inicial.
